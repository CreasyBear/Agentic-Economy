# Local planning workspace

Generated maps and local experiments under this directory are ignored working
material. They are not current product authority or a second delivery queue.
Previously tracked planning records are recoverable from Git history; local-only
corpora require their retained recovery bundle and are not shipped with the repo.

Use the [documentation index](../docs/README.md), [roadmap](../IMPLEMENTATION_ROADMAP.md)
and [current queue](../TODOS.md). Maintained infrastructure and recovery procedures
live under [infra/package4](../infra/package4/README.md). The
[archive index](../docs/archive/README.md#planning-snapshots) explains historical references.

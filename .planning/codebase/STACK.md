# Technology Stack
**Analysis Date:** 2026-09-01

<!-- refreshed: 2026-09-01 -->

- **Languages**: TypeScript is the primary language (`src/`, `convex/`, `tests/`, and `tools/`) with strict compiler settings in `tsconfig.json` and `convex/tsconfig.json`. The package is native ESM (`package.json` has `"type": "module"`). JavaScript and `.mjs` are used for build, development, seeding, and release tooling in `scripts/` and `tools/`; Tailwind CSS is authored in `src/styles/globals.css`.
- **Runtime**: Node `22.x` is the repository runtime contract (`.nvmrc` and `package.json`), with npm `11.5.1` and the checked-in `package-lock.json`. The published CLI declares Node `>=20` in `packages/cli/package.json` and is bundled for Node 20 by `scripts/build-cli.mjs`; Convex functions and the Vercel web runtime target Node 22. The authoritative runtime declarations are in `vite.config.ts` and `src/lib/deployment/manifest.ts`.
- **Frameworks**: React `19.2.7` provides the UI; TanStack Router/Start supplies file-based routing and server handlers in `src/router.tsx`, `src/routes/`, and `src/start.ts`. Vite `8.2.2` is the dev/build tool and Nitro provides the Vercel server preset in `vite.config.ts`. Convex `1.45.0` supplies the database, server functions, HTTP actions, scheduling, and React client; its application schema and component mounts are in `convex/schema.ts` and `convex/convex.config.ts`. Tailwind CSS v4, `tw-animate-css`, shadcn configuration in `components.json`, Radix primitives, and Lucide icons provide the UI system. Vitest `4.1.9`, Testing Library, and Playwright `1.61.1` provide unit/integration and browser verification tooling.
- **Key Dependencies**:
  - `convex`, `@convex-dev/agent`, `@convex-dev/workpool`, `@convex-dev/rate-limiter`, and `@convex-dev/aggregate` implement the authoritative backend, durable chat, bounded work, admission throttles, and aggregate projections used by `convex/`.
  - `ai` `^7.0.44`, `@ai-sdk/provider-utils`, and `@openrouter/ai-sdk-provider` implement the single model gateway in `src/modules/model-gateway/public.ts`; `src/modules/storefront/internal/web-discovery.ts` reuses that gateway for model-assisted web discovery.
  - `@clerk/tanstack-react-start` provides Clerk middleware, browser context, API-key validation, and OAuth/API-key administration across `src/start.ts`, `src/routes/__root.tsx`, and `src/lib/server/agent-access-auth.ts`.
  - `@x402/core`, `@x402/evm`, `@x402/extensions`, `@coinbase/cdp-sdk`, and `viem` implement x402 payment challenges, EVM verification, Bazaar metadata, managed CDP custody, and RPC receipt checks in `src/modules/capability-supply/internal/`.
  - `@modelcontextprotocol/sdk` supplies remote MCP client and public Streamable HTTP server support in `src/modules/capability-supply/internal/route-transport-mcp.ts` and `src/lib/server/mcp-api.ts`.
  - `zod`, `@cfworker/json-schema`, `@apidevtools/json-schema-ref-parser`, and `openapi-fetch` validate and bind admitted OpenAPI, HTTP JSON, and MCP contracts in `src/modules/capability-supply/internal/`.
  - `@stripe/stripe-js`, `@stripe/react-stripe-js`, and `stripe` implement browser Checkout, server-side money operations, Connect onboarding/transfers, and webhook verification in `src/components/ae/console/AeCreditTopUpPanel.tsx` and `src/modules/money/`.
  - `@sentry/node`, `@sentry/react`, `posthog-node`, and `posthog-js` provide sanitized server/browser error and product-event telemetry through `src/lib/observability/` and `src/start.ts`.
  - `@vercel/oidc`, `undici`, `http-message-sig`, `@noble/curves`, and `@noble/hashes` support Vercel OIDC-backed secret access, guarded outbound networking, request signatures, and cryptographic protocol boundaries in `src/modules/secrets/`, `src/modules/network-guard/`, and `src/lib/server/`.
- **Configuration**: Package commands and workspace boundaries are defined in `package.json`; the distributable CLI workspace is `packages/cli/package.json`. Vite/TanStack Start/Nitro/Tailwind/Sentry behavior is configured in `vite.config.ts`; TypeScript aliases and strictness are in `tsconfig.json` and `convex/tsconfig.json`; Convex schema, components, auth, and HTTP configuration are in `convex.json`, `convex/schema.ts`, `convex/convex.config.ts`, `convex/auth.config.ts`, and `convex/http.ts`. UI aliases and CSS variables are in `components.json` and `src/styles/globals.css`. Test/build entry points are `vitest.config.ts`, `playwright.config.ts`, and `scripts/`; environment names are documented in `.env.example`.
- **Platform Requirements**: Local development expects macOS-compatible tooling, Node 22, npm, a local or cloud Convex deployment, and the development launcher in `tools/dev/local-dev.mjs` (or the Vite command in `package.json`). Production serves the TanStack/Nitro web application on Vercel with the Node 22 runtime and deploys Convex functions/components through the Convex CLI; readiness and release checks are described by `src/lib/deployment/manifest.ts`. Browser suites additionally require Playwright Chromium. The checked-in `.vercel/project.json` currently reports a Node `24.x` project setting, which differs from the repository's Node 22 runtime declarations and should be treated as deployment metadata drift rather than the application contract.

# Imagine three brand territories for AE

- Type: prototype
- Status: closed
- Assignee: Main
- Blocked by: none (frontier)

## Question

What could AE *really* look like — real, emotive, visceral, the embodiment of
agentic-commerce trust? Produce three divergent, internally-consistent brand
territories to react to, each generated by a gpt-5.5 art-director subagent using
`brandkit` + `imagegen-frontend-mobile` + `imagegen-frontend-web`, grounded in
[`.planning/brand/GROUNDING.md`](../../brand/GROUNDING.md).

## Answer

Three territories generated, each with a `BIBLE.md` + 5 assets (identity board,
mobile first-scene, mobile handoff-receipt, web home hero, web storefront/proof).
Plus a skill-free raw baseline as a control.

- **A — Proof Ledger** (`explore/a-proof-ledger/`): ink + bone + **oxblood #8A2D24**,
  octagon-seal AE monogram cut by a ledger line, grotesk + mono. Receipt/proof-spine
  is the hero object. Strongest + most ownable; "AE has not booked or charged you."
- **B — Living Handoff** (`explore/b-living-handoff/`): warm neutral + **signal-green
  #2F6F4E**, relay-arc logo, routed dossier that travels out and returns as a receipt.
  Best motion / journey storytelling.
- **C — Real Marketplace** (`explore/c-real-marketplace/`): bone/stone + **clay #A85C3A**,
  registry-stamp doorway mark, "the trustworthy clerk at the threshold." Warmest copy;
  photographic renders came out murky (weak spot).
- **Raw baseline** (`explore/z-raw-baseline/`): no skills — defaulted to star-reviews,
  "verified" badges, retired-Daylight amber, glowing AI-network map (all off-contract),
  but donated photographic warmth + "owner inbox/source context" + deep-teal.

Verdict feeding ticket 002: converge on a **Proof-Ledger spine + Handoff motion +
Marketplace warmth** fusion; all reference north stars point at the evidence/receipt core.

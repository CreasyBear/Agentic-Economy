## Trust Boundaries

| Boundary | Description |
|---|---|
| URL/browser → server loader | Browser state is input, never eligibility/currentness authority. |
| ordinary-language query/model interpretation → source retrieval | Untrusted proposals must resolve only to registered constraints; stated preferences cannot silently become or cease to be hard constraints. |
| semantic result → human controls | Rendering must not widen into inquiry/effect behavior. |
| GenUI proposal → presentation resolver | Untrusted output may adapt registered density/emphasis only and must never delay deterministic truth or control disclosure state. |
| external published-details navigation | Query/referrer and endpoint execution must remain contained. |

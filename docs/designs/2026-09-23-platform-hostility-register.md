A listing should answer, in this order: **what it does → can I call it now and at what cost → what evidence and accountable Provider support it → what is the one honest next action**. The sticky action panel can offer Quote, Try in chat and copy CLI/MCP. The key-facts row uses only declared or measured price basis, readiness, payment mode and auth. Jev multi-call bundling is outside this wave. Signed-in chat purchases use an owner-scoped agent key/grant under the existing TrustedChatAuthority, with an explicit confirmation card before each Call and a result card afterwards, not a synthetic principal.

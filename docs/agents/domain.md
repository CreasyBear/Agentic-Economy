# Domain Docs

This is a single-context repository.

Before exploring or changing the domain, read:

- `UBIQUITOUS_LANGUAGE.md` at the repository root.
- Relevant decisions under `docs/adr/`, when present.
- `AGENTS.md` for the current AE product and assistant trust contract.

Use glossary terms in issues, tests, interfaces, and implementation. Avoid synonyms explicitly rejected by the glossary. If a required concept is absent, note the language gap for `/domain-modeling` rather than inventing competing terminology.

Surface any conflict with an existing ADR explicitly; do not silently override it.

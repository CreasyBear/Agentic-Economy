## Root causes found while landing

1. The Convex CLI's anonymous-deployment codegen needs the local backend to start; a 30 s default startup timeout failed once under load and passed with `CONVEX_LOCAL_BACKEND_STARTUP_TIMEOUT_SECS=180`.
2. The route tree is generated by the TanStack Start Vite plugin, not a standalone CLI; a new API route needs a `vite build` (or dev server) before typecheck sees it.
3. The swarm's "duplicated ref-format string" (rows 3 and 43) had one real site; the shared constant now serves the tool ref and the new call ref usage.

## Behavioural findings for the swarm

- `/api/ready` never changes HTTP status on commercial state; clients that want "sellable" must read the body.
- The `/status` page's refresh is a router invalidation, not a client fetch; probe results carry one request reference per page load.
- `ae supply calls` orders newest-first across a provider's Tools by merging bounded per-Tool pages; providers with more than 50 current Tools see a bounded view.

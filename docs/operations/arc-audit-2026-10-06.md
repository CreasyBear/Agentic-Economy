## Policy and ordered fix waves

**Repo WCAG/focus rules override Arc skill's “no focus outlines” rule** (`~/.claude/skills/arc/accessibility.md:5-20`, `SKILL.md:45-50`). PA-13/R01 is **P0**, irrespective of upstream styling. The current `.arc-market :focus-visible` bridge supplies a `!important` ring (`src/styles/arc-market.css:66-72`), so source-level `outline:none` is not itself proof that the mounted UI lacks focus; verify keyboard focus after each change. Keep Base UI adaptations, native links, truthful finance/status, exact output, and reduced motion. No wholesale Arc reinstall; no Pro-source reconstruction from preview.

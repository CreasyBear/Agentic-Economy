# Arc elevation plan — 2026-10-06

**Status:** decision and execution contract, not an implemented migration. Scope is the 49 vendored entries in [the inventory](arc-audit-2026-10-06.md#inventory), their market derivatives, and the three read-only refactor lanes in `/tmp/arc-audit/`. `BROKEN` below means **upstream-source fidelity**, not a demonstrated runtime failure. The previous [fix register](arc-audit-2026-10-06.md#policy-and-ordered-fix-waves) describes targeted edits to locally adapted Arc; this plan supersedes that *vendor-editing method*, not the findings or user-visible safeguards. Do not restore preview data, simulated actions, demo MFA, imaginary prices, or a sample app shell to obtain a pristine diff.

## 1. Doctrine and stop rules

1. **Vendored is upstream-pristine.** `src/components/arc/**` contains only upstream files installed/overwritten with `npx shadcn@latest add @uiarc/<id>` or `npx shadcn@latest add @uiarc-pro/<id>`; resync the same way. The Pro registry is configured in `components.json:21-30`. No AE edits, renamed Pro ports, Pro-source reconstruction, or locally adapted copy under `arc/`. Check the exact installed registry item and declared dependencies before a cutover. Do not log or commit credentials. Licensed Pro source is installed and consumed, **never edited by AE**. Cite guidance: `~/.claude/skills/arc/SKILL.md` §§Workflow, Install, Wire.
2. **AE owns the edge.** For each migrated feature, target `src/components/ae/<domain>/<feature>/`: `<Name>.tsx` container, `use<Name>.ts` for lifecycle/callbacks, `<feature>.contracts.ts` for DTO/props, `<feature>.view-model.ts` for pure mapping, and private presenters only when needed; reuse existing compounds instead of boilerplate. Only containers/hooks know routing, Convex/Clerk, money, permissions, status truth, or network effects. Arc gets documented props/slots and callbacks. Keep domain DTOs out of `.tsx`, keep AE imports out of `arc/`, and do not call backends from leaves. For Pro-derived market files, do **not** relocate copied Arc implementation under `ae/` to evade the vendor boundary: E0 must replace them with a pristine public block plus an original AE adapter, or retire/retain only an independently authored AE composition with a recorded reuse-vs-handroll reason. When a public API cannot express a region, compose/wrap outside `arc/` or keep an eligible AE-owned feature; never edit vendor internals or silently substitute demo behavior. Guidance: `~/.claude/skills/arc/components.md` §Wiring rules, `composition.md` §§Plan/States/React correctness, `~/.claude/skills/arc-pro/refactor-to-arc.md` §§1–3.
3. **One provenance ledger.** E0 creates `docs/operations/arc-vendor-manifest.md`, one row per installed upstream ID with tier, exact install command, retrieval date, upstream URL and SHA-256 of obtained registry contents (and mapped file hashes for multi-file IDs); distinguish AE derivatives. No per-file AE provenance headers. Hash proves bytes/version, not licence grant. Record retired installs/importers before removal. The current Free registry lists `stepper`; its local “Arc Pro” header is not proof of tier or retroactive rights (`/tmp/arc-audit/ProDrift.md` §stepper; `/tmp/arc-audit/FreeBreakage.md` lines 146–147).
4. **Accessibility prevails over Arc styling.** `~/.claude/skills/arc/SKILL.md` §Never do, `~/.claude/skills/arc/checklist.md` §Accessibility, `~/.claude/skills/arc-pro/accessibility-audit.md` §3 and `~/.claude/skills/arc-pro/refactor-to-arc.md` §6 say no outline. **Repository WCAG visible focus overrides all four.** Keep a visible `:focus-visible` indicator in AE edge CSS (`src/styles/arc-market.css:66-72`), including overlays/portals not covered by `.arc-market`; test in both themes. Never change upstream files for this exception. Keep 44px targets, reduced motion and Base UI behavior where required at the edge; if an upstream public API cannot satisfy a contract, retain an AE-owned control rather than falsely claiming parity.
5. **Reuse decisions are evidence-based.** Compare full semantics, declared dependencies, runtime/bundle boundary, and internal helpers before each replacement; record `KEEP` or `REPLACE` and why. Matching names alone do not establish equivalence. Do not import transitive-only packages or run exact money through floats. Guidance: `reuse-vs-handroll-audit` §§Procedure/guardrails; `de-handroll-audit` §§Procedure/Honesty. Follow `~/.claude/skills/arc-pro/refactor-to-arc.md` §§4–5: one pattern and all consumers, prove parity before continuing.

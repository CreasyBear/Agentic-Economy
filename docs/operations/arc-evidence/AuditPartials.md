## Source and confidence limits

- Upstream Pro markdown describes demo anatomy, **not** a production API obligation. Sample subscriptions, fake invoices, simulated approvals, guessed prices and stock must stay removed unless a real AE data/action contract exists. No Pro source comparison was available; `ARC_PRO_TOKEN` was absent in the upstream lane. [INFERENCE] Arc source performance changes beyond the free downloaded files and public docs cannot be assessed here.
- Full state ownership is frequently outside the vendored leaf. The `CreditLedgerPanel` BillingHistory shell does not imply missing transactions because `AccountHistory` owns them; `AeToolInputForm` does not imply missing submit because the page owns it. Do not score these intentional splits as P1 partial implementations.
- Repo accessibility rules supersede Arc docs' no-outline instruction; PA-13 documents the affected Settings and Security focus targets, so no Arc no-outline styling should be restored elsewhere.

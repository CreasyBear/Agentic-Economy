# Arc consumer audit: admin and operator (UA)

Scope: `src/components/ae/admin/**`, `src/components/ae/operator/**`, `src/routes/_operator*` (including `_operator/`), and `src/routes/admin*` (no standalone match). Source review only; no browser, build, or tests run under the read-only assignment.

**Direct `button.module.css` imports in this scope: 9 files out of the repo's 87 direct importers.** Six are under `src/components/ae/admin/` (`audit/AdminAuditPage.tsx:6`, `exceptions/components/ExceptionEvidenceSheet.tsx:5`, `metrics/components/MetricsControls.tsx:2`, `overview/AdminOverviewPage.tsx:9`, `overview/components/OldestExceptions.tsx:4`, `treasury/TreasuryMetrics.tsx:7`); one is the operator table (`src/components/ae/operator/AeOperatorDataTable.tsx:30`); two are operator routes (`src/routes/_operator/owner.settings.integrations.tsx:4`, `src/routes/_operator/owner.settings.privacy.tsx:3`). Eight are product-reachable; `MetricsControls` is test-only. The direct CSS consumers style navigation/download/row-action anchors, not `<Button>` actions (e.g. `AdminAuditPage.tsx:47-52`, `MetricsControls.tsx:24-30`, `AeOperatorDataTable.tsx:351-373`, `owner.settings.privacy.tsx:18-22`); do not blindly convert anchors to buttons. Focus checks: `src/styles/arc-market.css:8-29,66-72` sets a visible `--focus-ring` and `:focus-visible` outline, overriding Arc's transparent default (`src/components/arc/foundation.css:46-47`). The commercial-policy select suppresses the browser's native outline **but supplies a visible `ring-2`** (`src/components/ae/admin/treasury/CommercialPolicyActions.tsx:19`); it is not a missing-focus-ring finding.

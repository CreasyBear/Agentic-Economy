# Free Arc source-breakage census — 2026-10-06

**Snapshot:** 33 free registry IDs, 83 upstream files; 69 mapped local files (including renamed/relocated files), 14 absent upstream files. Across all upstream file slots: PRISTINE 3, PROPS-ONLY 43, STALE 3, BROKEN 34. At whole-item level (most severe file class per item): PRISTINE 0, PROPS-ONLY 17, STALE 2, BROKEN 14.

Source: `/tmp/arc-upstream-audit/<id>.json` `files[].content`, canonical `https://uiarc.dev/r/<id>.json`, compared to the mapped files under `src/components/arc/`. Counts `+local/-upstream` are actual `diff -U0` added/deleted physical lines, treating an absent file as an empty local file; provenance comments, formatting, and line-ending changes count. Renames mapped: `drawer.tsx`→`Drawer.tsx`, drawer CSS likewise, `tabs.tsx`→`Tabs.tsx`, comparison-table TSX/CSS→`market/ComparisonTable.*`, and empty-states art→`empty-states/empty-states-art.ts`. An absent row has **no vendored file**; it is an item-coverage classification rather than a claim that a nonexistent file contains code.

**Definitions:** PRISTINE = byte-equivalent line comparison (zero diff); PROPS-ONLY = upstream component anatomy/core renderer retained, with limited props/types, accessible state/focus, theme/geometry and provenance edits (the name does *not* claim CSS files have props); STALE = specific upstream improvement present in downloaded snapshot but missing locally; BROKEN = upstream internals/engine/regions rewritten or removed, or AE-specific product presentation/state inside vendor source. BROKEN measures source-pristine doctrine, **not** a verified runtime defect or an instruction to restore simulated demo features. Base UI substitutions, WCAG focus and exact money/status rules must be preserved at an appropriate boundary; do not overwrite blindly.

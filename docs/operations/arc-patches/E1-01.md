# E1-01 Arc patches and keeps

## Vendor patches

None. E1-01 installs or edits no files under `src/components/arc/**`.

## Kept AE components

- `src/components/ae/shared/action-link/` keeps navigation and actions semantically separate: native `href` and anchor/router-link composition for navigation; an explicit `onAction` callback and button for actions. Arc's public `Button` is reused for actions without `labelLayout`.
- **KEEP: AE `labelLayout` action variant.** The captured Free `button` registry API exposes `variant`, `size`, and `loading`, but no `labelLayout` (`/tmp/arc-upstream-audit/button.json`). Its label slot is sized to its content, so the full-width `start`, `between`, and `wrap` layouts cannot be expressed via documented props or root `className`. The edge renders a native action button for this specific layout rather than reaching into vendor CSS or silently losing layout. Pending callbacks, disabled guards, visible focus, and the 44px target remain at the AE edge.

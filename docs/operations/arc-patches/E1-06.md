## Decision and AE behavior

The Pro data-grid is not a fit: its documentation centers spreadsheet editing, fill-handle, clipboard and bulk actions, and recommends a sortable data table for read-only sorted/selectable records. The operator table instead requires TanStack-controlled sorting/selection, exact `BigInt` sort inputs, and row-action focus management. No Pro dependency was added.

Moved the AE renderer and its CSS to `src/components/ae/shared/sortable-data-table/AeSortableDataTable.tsx` and `AeSortableDataTable.module.css`; its AE contracts live in `sortable-data-table.contracts.ts`. Operator, purchase-activity, and directory consumers with exact sort or focus requirements use that AE component. Simple read-only consumers use pristine Arc's public table API. The moved behavior test remains at `tests/unit/ui/arc-sortable-data-table.test.tsx` and targets the AE renderer.

Sources: [Arc sortable data table](https://uiarc.dev/components/sortable-data-table/markdown), [Arc data grid](https://uiarc.dev/components/data-grid/markdown).

### `AeComparisonTable`

- **Path:** `src/components/ae/shared/comparison-table/`.
- **Reason:** The pristine Arc block accepts comparison columns and grouped values, but has no per-cell source evidence or per-column action slot; its only CTA belongs to one highlighted column. Those gaps prevent it from preserving each Tool's published-fact provenance and its own Inspect Tool link. The buyer showcase's Compare surface requires both. The Pro `data-grid` is an editable spreadsheet, not a read-only comparison matrix; `plan-comparison` is a no-props sample pricing block. `sortable-data-table` is for sortable records, not this comparison. Arc MCP search was attempted but its endpoint returned 401 and requires sign-in; the public Arc catalog and these candidate contracts were checked, and no better-fit item was identified.
- **Upstream report text:** “The comparison-table API exposes source-agnostic cells and only one CTA in the highlighted column. AE Tool comparison needs provenance for each published fact and an individual inspection link for every candidate. Please add a per-cell source slot and per-column action prop so this surface can use the block without flattening its evidence or dropping navigation.”

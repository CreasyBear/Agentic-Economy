## Kept AE component

`src/components/ae/shared/usage-meter/AeApproximateQuotaMeter.tsx` retains the compact exact-limit presentation at monthly spend, agent directory, and Treasury. The pristine Arc public API takes numeric `segments`, `limit`, and `warnAt`; it has no `compact`, `summary`, or exact `limitState` props. Deriving status from rounded percentage can contradict exact money state at the threshold, while Arc's full legend is too dense for compact rows. AE keeps exact limit classification and accessible summary at the edge; the tiny bar only displays the approximate percentage and uses the supplied exact state for its status token. Generic allowance displays continue to use Arc `UsageMeter` directly.

Upstream report: “Use a usage meter for a fixed allowance, such as storage or seats, when people need to see what takes the space and how close they are to the limit.” Its `when not to use` says to use `progress` for task completion, `bar-chart` for categories without a limit, and `gauge` or `stat-card` for a single headline metric.

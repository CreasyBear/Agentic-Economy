# E1-03 Arc drawer patch record

## Vendored patches

- **`src/components/arc/drawer/drawer.tsx` — caller-provided close label.** Added optional `closeLabel`, defaulting to the existing “Close drawer” name, and used it as the close control's accessible name. This preserves `AeAppHeader`'s existing “Close public menu” name. Upstream report: the close control currently hardcodes `aria-label="Close drawer"` and exposes no prop for a caller-specific accessible label. The patch only changes that name when a caller explicitly provides one.

## AE edge adapter

- **`src/components/ae/shared/arc/drawer/` — `AeDrawerContent`.** Wraps Arc Drawer content to retain the AE `.arc-market` visible-focus scope and preserve the former `Close` default accessible name; explicit caller-specific names such as “Close public menu” remain intact. It also maps the existing `data-phone-bottom` marker to Arc's `side="bottom"` at the existing 639px breakpoint, preserving the Add Credit mobile sheet's bottom-up interaction and layout without adding AE behavior to vendor CSS.
- Drawer consumer migrations use Radix `asChild`, `onInteractOutside`, and `onCloseAutoFocus` directly. The old Base UI-specific `render`, `finalFocus`, and outside-press callback shapes are not retained as compatibility APIs.
- **`AeToolInspector` focus return.** Its shared and inline schema triggers live under one Radix dialog root, so the opened trigger is captured on auto-focus and restored on close instead of Radix's last-registered trigger.

## Kept AE components

- None. `AeRecordSheet` remains the AE record-context/open-state edge, composed with the Arc Drawer.

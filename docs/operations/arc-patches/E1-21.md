# E1-21 Arc line-chart disposition

## Marketplace dashboard gap-aware chart

- **Decision:** Restore `@uiarc/line-chart` pristine for hero-section consumers; do not use it for sparse marketplace-dashboard metrics. Its missing-value contract treats absence as zero, which contradicts dashboard snapshot semantics.
- **Kept AE component:** Keep the dashboard's AE chart renderer rather than route nullable points through Arc. It splits the plotted path at absent days, preserves observed zero values, exact money/value labels, integer-count ticks, keyboard exploration and accessible table gaps. The marketplace dashboard's dedicated E2-13 card owns its later composition move.
- **Consumer migration:** `src/components/arc/blocks/marketplace-dashboard/metrics-dashboard.tsx` renders its gap-aware path for all series. KPI values remain static formatted text; rolling SlotText is not part of the buyer/supply showcase contract.
- **Vendor state:** `src/components/arc/line-chart/line-chart.tsx` and `line-chart.module.css` are PRISTINE, byte-matched to current registry content (SHA-256 `33bb893b21de8ef07ddb2e28a5ee4d28837a28ad8422fc99a437cdb2be938f0b` and `0a761cc358588f948f4a4689ccfc9f57f73b3f043f07599e0233e025f30a919f`). No vendor patch is needed.
- **Evidence:** `tests/unit/admin-console/founder-dashboard.test.tsx` verifies a missing-day path break and distinguishes an observed zero from an absent snapshot.

# E1-10 Arc patch and keep record

## `checkbox` semantic patch

- **Diff:** Preserve caller `aria-describedby` references and append Arc's generated description ID when present.
- **Reason:** The pristine registry implementation replaces the caller's description reference with `undefined` when `description` is absent, or drops it when Arc supplies its own description. `AeToolInputWidgets` passes generated help/error IDs, so dropping them disconnects instructions and validation from the checkbox.
- **Upstream report:** The documented Checkbox API supports native `aria-describedby`, but the registry root overwrites caller references with only its generated description ID (or `undefined`) after spreading `props`. Preserve caller references and append the generated description ID. https://uiarc.dev/components/checkbox/markdown

## Retired unconsumed extensions

- **API:** Retire the local `readOnly`, `nativeButton`, `render`, and function-valued `className` extensions. Repository source-use search found no Checkbox callers for these extensions; the only `compact` product use was migrated by E1-06.
- **Reason:** These are undocumented local differences from Arc, with no remaining AE consumer; no adapter or kept component is needed.


## Kept AE components

- None. The remaining consumers use the documented Arc API; density and visible-label migrations are owned by E1-06 and E1-03.

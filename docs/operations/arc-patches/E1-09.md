# E1-09 Arc patch and keep record

## `empty-state` semantic patch

- **Diff:** Add optional `role?: "status" | "alert"` and `titleAs?: "h2" | "h3" | "p"` to `EmptyStateProps`; forward `role` to the root section; render the requested title element with `styles.title`, changing CSS from `.root h3` to `.root .title`. Defaults remain upstream `h3` and no explicit role.
- **Reason:** AE needs truthful `status` versus `alert` regions and preserves existing `h2`/paragraph heading semantics across its 29 shared empty-state sites; these are accessibility semantics, not styling or product-specific behavior.
- **Upstream report:** The documented API does not include either prop and states: “Renders a section with an h3 title; pass label to name the region.” https://uiarc.dev/components/empty-state/markdown

## Kept AE composition

- **Component:** `src/components/ae/shared/arc/empty-state/AeEmptyState.tsx` composes the patched public Arc component and keeps AE-owned recipes, caller actions, action feedback, compact density, and exact financial reassurance outside vendor source.
- **Reason:** Arc's public item does not model those AE-specific states; its component does not replace the application-owned callback/toast and money-copy boundary.
- **Cutover:** All AE consumers use this edge adapter. The unused partial `empty-states` demo-art import and its private CSS composition are removed.

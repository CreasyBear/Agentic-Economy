EvilCharts Recharts bar chart and its chart, tooltip, legend, background and brush support components. Installed using the official shadcn registry https://evilcharts.com/r/recharts-bar-chart.json on 2026-09-08. Source: src/components/evilcharts/. Local changes preserve upstream behavior while adapting optional-property types and component props to AE strict TypeScript; remove one unused type import. AE composes these components with full-directory distributions, semantic colours and accessible count/filter tables. No documentation app or demo datasets copied.

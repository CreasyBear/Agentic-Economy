Use case: ui-mockup.
Asset type: high-fidelity desktop marketplace design concept for Agentic Economy (aecon).
Primary request: Visualize the compact, familiar marketplace architecture we have agreed to compose with actual Arc React blocks and components. Produce one exceptionally polished, front-facing, full-screen desktop interface, not a perspective device mockup or marketing poster. Wide landscape composition, crisp readable interface text. This is a design concept, not a screenshot of the live app.

Brand: warm chalk background #e8e4da, slightly lighter cream surfaces #f2efe7, charcoal #141414 text and primary buttons, restrained forest green #24543d selection accent. Manrope-style modern humanist sans typography, regular and medium weights; monospaced prices/schema fields. Arc's concentric rounded control/panel geometry, roughly 18px/26px/34px radius scale, thin quiet borders, 44px control heights. Warm, tactile, editorial clarity with the familiarity of a mature marketplace. Avoid generic analytics-dashboard design.

Composition:
A compact horizontal app header: text wordmark "aecon" at left, "Market" and "Chat" navigation, quiet account control at right. The content begins close beneath the header. Modest heading "Tool market" with one short supporting line "Find a useful contribution." A secondary "Ask an agent" button links conceptually to chat. A prominent but compact catalogue search field reads "Search Tools". Four familiar tabs read exactly "Collections", "Tools", "Providers", "Saved"; Tools is selected. One restrained control row: three category chips "All", "Data", "Research"; "Filters", "Sort: Relevance", and a Grid / Table segmented control with Grid selected. Small accurate label "4 Tools on this page". Results begin within the first viewport. No enormous hero or prompt composer.

The main region is the Arc ProductListing composition adapted to four Tool records in a balanced four-column gallery. The cards are coherent self-contained objects, containing a recognizable identity header, useful contract preview, title, short contribution description, price/access line and independent Inspect / Compare / Save controls. Preview media must be designed from published input/output information: attractive typography, tiny structured JSON examples, and simple Input → Output diagrams. No invented stock photos, image generation artwork, user ratings or performance charts inside the product cards.
Four illustrative records:
1. "Current weather", short line "A city in. Current conditions out.", preview input "city" → output "temperature, conditions". Price line "US$0.02 per Call", access "Directory listing".
2. "Timezone lookup", short line "Coordinates to a timezone.", preview "latitude, longitude" → "timezone". Price line "Price unavailable", access "Readiness unknown".
3. "Read a webpage", short line "A URL to readable text.", preview "url" → "text". Price line "Price unavailable", access "Directory listing".
4. "Search public records", short line "A query to sourced records.", preview "query" → "records". Price line "Price unavailable", access "Catalogue-only".
Use small quiet source text "Published metadata". Prices are flat exact strings, no discounts, no implied currency conversion. The first two cards have a forest selection outline and checked Compare controls; the others are unselected. Unknown access never looks like a positive success badge.

At the bottom of the viewport, place one compact Arc-style comparison tray with the two selected names, "2 of 4 selected", small remove controls, "Clear" as a quiet action and "Compare Tools" as one charcoal primary button. Keep it slim, outside the cards, and do not obscure record facts. A visible next/previous control row may say "Previous" and "Next"; do not invent total pages or a global catalogue count.

Finish with a small outside-content caption "Design concept · illustrative records". This caption makes the sample records explicit.

Craft constraints: Use the authored look of Arc ProductListing, SearchField, Tabs, ChipGroup, FilterToolbar, Select, SegmentedControl and Button, with consistent spacing, precise axes and restrained shadows. Strong recognizable information hierarchy, useful preview compositions, every title readable, compact density without cramped text. Creative quality comes from elegant contribution previews and proportion. No huge marketing banner, gradients, neon, glossy 3D illustrations, fake review stars, shopping carts, mandatory purchase approvals, random logo wall, dense technical sidebar, or giant pill buttons.

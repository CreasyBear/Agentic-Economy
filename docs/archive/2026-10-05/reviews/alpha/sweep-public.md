## Not reachable and why

- **A real non-sandbox `/$slug` Business profile and `/$slug/ucp`:** `/api/businesses?limit=30` page 1 contained exactly two sandbox Businesses (`sandbox-aecon-reference`, `sandbox-aecon-testnet`), `hasMore: true`; following its cursor returned zero additional rows with `hasMore: false`. The required product test uses real admitted x402 supply, so neither sandbox Business was used to pretend a real Business journey passed. `/$slug` unknown-path 404 *was* tested.
- **Valid `/s/$shareToken` and revoke:** `chatShares.issueShare` blocked by absent/short `AE_CHAT_SHARE_SECRET` on local Convex (row 3). Invalid token was exercised.
- **Actual paid purchase:** explicitly prohibited for the sweep (no real-money payments). Admitted Tool detail and Connect an Agent transition were exercised; Quote/Call money flow belongs to buyer-account/sandbox sweep.
- **Full anonymous follow-up:** the initial web-search question yielded no candidate card and an opaque cursor (row 2). A prior isolated anonymous invocation streamed four candidate cards after 26 s but did not finish within that observation window; the separate 45 s completed invocation above is the verdict. No anonymous durable thread URL is expected; it remains browser-tab state.
- **Desktop clipboard copy after restart:** browser harness permission reported `clipboard-write: denied`; API reference click displayed its honest failure status. Earlier Codex command copy returned expected text before permission denied. Do not classify browser permission denial as a product bug without a normal browser reproduction.
- **Machine HTTP signatures public key directory:** intentional 404 because no public WBA directory key configured, not a broken handler.

**Transient operational observation:** During an initial signed-in FX turn the Convex WebSocket closed with code 1006; both 3024 and 3210 then refused connections briefly. Main restored the stack and stale OpenRouter key. All public/static pages were re-walked after restart. Directory AUD prices that briefly said “AUD estimate temporarily unavailable” before restart later showed A$0.02 for the same weather listing both in `/market` and detail; do not treat the early fallback alone as a persistent pricing defect. Final status after restart: five checks operational. **Open tally: 4 blockers, 2 major, 5 minor.**

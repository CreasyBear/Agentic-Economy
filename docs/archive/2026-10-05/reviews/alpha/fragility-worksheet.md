# Fragility worksheet — J1–J8, inventory/classification/analysis

**28 September 2026.** Protocol steps 1–3 only. Rows deduplicate the [external](fragility-external.md), [backend](fragility-backend.md), and [UI](fragility-ui.md) maps and the five [live sweeps](sweep-public.md); source references below identify the executable boundary. Research in [stability](research-stability.md), [stack](research-stack.md), [method](research-method.md), and [journeys](research-journeys.md) informs classification and transitions, **not** claims of successful injection. Product authority: [maturity decisions](../maturity/00-decisions.md), standing fragility directive. Code is a moving target while slices edit in parallel: the worksheet records the checked boundary, not a claim that every cited defect remains open after its owner lands.

**Reading the table.** H = genuinely hard to a truthful result; S = already optional/background; C = currently on a critical path but can be softened or removed. For an H edge, a localized refusal or status check is a *recoverable journey outcome*, not permission to bypass authority. `sync/async` describes the **current** edge (including UI render joins and deployment boot); `async` background work can still wrongly gate a synchronous read. The invariant column names the protected truth and blast radius. S/O/D = severity / occurrence / difficulty detecting *before user impact*, high/medium/low. `observed` means a local sweep reproduced the effect, **not** a population frequency; `source risk` means a code-grounded failure chain without fault injection; `prerequisite` means the sweep could not exercise the protected operation. A `none` exit is a defect. Proposed changes are assignments, not verified implementations. No real-money Call or production fault was injected for this worksheet.

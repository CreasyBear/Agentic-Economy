# Maturity design review — 27 September 2026

**Thesis:** A buyer can discover a real Tool, choose and purchase with truthful authority and exact money, while a Provider and operator can act on facts rather than presentation claims. **Integrity: mixed.** This is a non-interactive design review; the interview was skipped. Joel’s decisions override the brief, and the value gate is safer, performant, ergonomic, intuitive or maintainable (`docs/reviews/maturity/00-decisions.md:5-21`; `docs/designs/2026-09-27-maturity-subagent-protocol.md:12-20`). The seven designs are proposals, not served-release proof.

Do not publish USDC as the buyer price or `<A$0.01`; X4 requires rounded-up `A$0.01` for a positive sub-cent amount and exact ledger/export amounts (`00-decisions.md:16`; `src/modules/money/internal/display-price.ts:8-39`).

The current wire still uses `matched` (`src/modules/registry/tool-choice-contracts.ts:92-98,169-185`), so do not silently ship documentation ahead of the cutover. This preserves X1/X2/X3 (`00-decisions.md:12-14`).
3. **G2 need-mode cutover has no assigned consumer migration.** G2 F changes `tool.procure` to selection-only `needs_input` but names only engine/action files, while promising HTTP/MCP/CLI schema consumers (`G2-design.md:30,43,53`). Assign the endpoint schema, registry descriptor, CLI and MCP routing/rendering and their tests to one serial integration owner before switching the output; currently the action advertises a payment effect and one-turn purchase, and the engine reserves identity *before* need selection and fabricates free inputs (`src/modules/capability-execution/procure.actions.ts:26-93`; `src/modules/capability-execution/procure-engine.ts:180-194,218-276`). No paid **or free** invented inputs (X7, `00-decisions.md:19`).
4. **Do not publish G3’s public paid-path copy as current availability before release proof.** G3 E changes `/for-agents` to a public connect→fund→Quote→Call claim (`G3-design.md:43`), but its own acceptance still needs the hosted CLI, eligible account and a controlled paid Call (`G3-design.md:57`). Gate that copy on X6’s actual entry-release paid acceptance on one pinned revision, or phrase it as an ordered setup instruction without asserting observed availability (`00-decisions.md:18`; `docs/designs/2026-09-27-maturity-subagent-protocol.md:56-64`).
5. **Do not retire the installable CLI channel before its replacement is public.** G7 deletes the deploy archive in the release-artifact slice, yet its chosen public GitHub Release is still outsider-inaccessible/unproved (`G7-design.md:5-6,27,33,45`). X6 requires a hosted, provenance-verifiable install *at* public paid release (`00-decisions.md:18`). Approve the public release home, publish/verify the same archived bytes and install path as an outsider, then cut over download copy/channel in the entry-release revision; no permanent parallel legacy channel.

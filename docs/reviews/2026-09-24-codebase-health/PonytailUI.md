## Handrolling: replace or KEEP, with coverage proof

1. **Unused mutation/copy-toast wrapper → DELETE, not a replacement migration.** The declared `sonner` dependency is `^2.0.7` (`package.json:131`) and its installed `toast.success/error/promise` API exists (`node_modules/sonner/dist/index.d.ts:130-145`). The wrapper has no runtime caller; remove it rather than introduce a second Sonner idiom. Clipboard functionality remains in browser `navigator.clipboard.writeText` via the existing shared hook (`src/lib/ui/copy-text-to-clipboard.ts:1-6`, `src/hooks/use-clipboard-copy.ts:22-39`).
2. **Two hand-written copy-feedback timers → REPLACE only shared mechanics.** The existing `useClipboardCopy` already owns native Clipboard API, status, timeout and callbacks (`src/hooks/use-clipboard-copy.ts:4-39`); `AeCopyPublicUrlButton.tsx:53-74` and `AeKeyRevealDialog.tsx:126-139` duplicate those mechanics. Keep their product-specific telemetry, secret warning, errors and selectable fallback. `AeCopyCommand.tsx:34-41`, `AeCopyReference.tsx:14-16` and `CodeBlockCopyButton` at `src/components/ai-elements/code-block.tsx:440-454` prove current reuse.
3. **Button variant/size mirroring → REPLACE with installed Base UI/shadcn wrapper's existing type.** `AeCopyPublicUrlButton.tsx:11-36` reproduces the same literal values and identity maps already represented by `Button` props (`src/components/ui/button.tsx:8-19`, `src/components/ui/button-variants.ts:12-38`). No adapter behavior to preserve.
4. **Tables → KEEP.** The 555-line `AeRecordTable` looks custom, but it delegates sorting/filtering/selection to `useReactTable`, `getFilteredRowModel`, and `getSortedRowModel` (`src/components/ae/operator/AeOperatorDataTable.tsx:3-15,146-218`). It implements AE-specific mobile, skeleton, accessible row action, selection and status rendering (`:250-375`). `@tanstack/react-table` is declared at `package.json:101`. Replacing the entire component with raw TanStack would lose these product responsibilities; the three-line dead alias is separable.
5. **Cursor pagination → KEEP.** `useProviderCataloguePages.ts:22-71,78-79,121-178` groups a sorted Tool cursor stream into 12 distinct hosts with capped fetches and deduplication; `AeX402Directory.tsx:109-158` pages raw Tools by cursor. TanStack Table's row pagination does not implement this server/grouping protocol. Native `<nav>`/links and Button already render pagination (`AeX402Directory.tsx:428-440`); `ActivityPaginationControl.tsx:6-30` and `HomeDirectoryPagination.tsx:5-29` carry distinct product-specific load/error copy. No new generic pagination primitive recommended.
6. **Command palette keyboard intent → KEEP.** `useCommandPaletteSelection.ts:55-112,171-250` tracks keys pressed before async results arrive and replays selection/activation only when the matching query resolves. The UI already uses installed `cmdk` via `src/components/ui/command.tsx:3-5,16-28`, with the palette consumer at `src/components/ae/command-panel/tools-search-page/ToolsSearchPage.tsx:5`. Replacing the intent handler with cmdk's list navigation would drop the async-query edge case.
7. **Native disclosures/selects and focus → KEEP.** `WorkDisclosure.tsx:8-23` uses built-in `<details>/<summary>` rather than reimplementing disclosure. The four native `<select>` components observed include a two-option HTTP method picker (`AeProviderConnectionForm.tsx:79-90`); a shadcn Select migration adds markup/JS without needed behavior. Dialog and dropdown consumers import existing Base UI-backed primitives (`AeKeyRevealDialog.tsx:17-24`, `ThemeToggle.tsx:8-14`). The one custom roving-focus primitive (`src/components/ui/roving-focus.tsx:105-185,197-245`) is only used for table row actions (`AeOperatorDataTable.tsx:437-489`); installed Base UI 1.8.0 does not export `./roving-focus` (`node_modules/@base-ui/react/package.json:61-76` plus missing package subpath). A toolbar is not a semantic table-row replacement. Do not falsely claim Base UI covers it.
8. **Forms and formatting → KEEP.** `@rjsf/shadcn` handles provider-supplied JSON Schema inputs (`DirectoryToolPlayground.tsx:1,62-75`); `TaxProfileForm.tsx:74-125` handles a fixed legal/tax form with domain validation and explicit diagnostics, not an arbitrary schema. `@tanstack/react-form` and `@tanstack/react-query` are **not declared** in `package.json:69-139`, nor is `motion`/`framer-motion`; recommending them as existing replacements would be false. Dates/counts use `Intl` in `src/lib/ui/format-time.ts:12-36,51-80`, money uses `formatDisplayAmount` (`owner-credit-format.ts:4-8,82-90`). The similarly named local Perth timestamp formatter deliberately includes `timeZoneName: 'short'` (`src/components/ae/admin/object-pages/object-pages.contracts.ts:89-101`), unlike the shared one (`src/lib/ui/format-time.ts:21-25`): **KEEP until display contract is intentionally unified**, not a drop-in duplicate. The two latency formatters differ for chart-axis compactness versus detail minutes (`AeToolLatencyChart.tsx:124-127`, `AeToolTrackRecord.tsx:95-101`): **KEEP**.
9. **Empty-state families → KEEP except a conscious visual consolidation.** `src/components/ui/empty.tsx:5-94` is a composable shadcn-style primitive; `AeEmptyState.tsx:17-39,67-111` adds role/recipe/financial reassurance/action-feedback semantics; `AeDegradedState.tsx:11-27` explicitly fixes `role="alert"`; `AeTableEmptyState.tsx:19-40` wraps a compact bordered table treatment; `CreditSectionEmptyState` (`AeAccountHistoryTable.tsx:36-48`) is an inline ledger text state. Similar nouns do not prove interchangeable UX. No claimed deletion of these live surfaces.

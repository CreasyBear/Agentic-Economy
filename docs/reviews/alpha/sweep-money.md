No new Call was created in this sweep. The existing −A$0.01 receipt was only used to test Help and the ledger link.

The approval card is specified to switch to “Quote expired” and “Get a fresh Quote”. Neither state appeared because no Quote was issued. `convex/lib/capabilityExecution/quotes/quoteValuation.ts:365-383`; `src/components/ae/shared/QuoteConfirmation.tsx:24-46`.
- **Second open of the success URL creating a second credit:** not observed. Balance moved A$5.00 → A$10.00 once.
- **Hosted Stripe receipt document:** the in-app row and Stripe receipt button were present; the external receipt URL was not followed.

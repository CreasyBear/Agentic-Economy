## Rejected / overstated

- **RATELIMIT-IP-01:** [SOURCE] Off-Vercel `trustedIngressIp` trusts request-provided forwarding headers (`src/lib/server/rate-limit.ts:137-150`), so it is spoofable in a self-hosted deployment; production ingress is explicitly Vercel (`vercel.json:1-4`) and on Vercel only `x-vercel-forwarded-for` is consulted. **Do not count as a present Vercel finding.** If self-hosting becomes real, take the client IP from the configured trusted ingress only; a Fetch `Request` does not carry an authoritative socket peer address. Local development spoofing is not a production vulnerability.
- **REDIRECT-PORTAL-01:** [SOURCE] `validatePortalReturnUrl` would accept another origin with `/owner/credit` (`src/lib/server/stripe-customer-portal.ts:67-94`). `createStripeCustomerPortalSession` always calls that validator (`:154-157`), but its only production caller passes `${baseUrl}/owner/credit` (`src/modules/money/internal/saved-payment-methods-http.ts:168-173`). The unit case named “refuses open redirects” checks `https://evil.test/phish`, `//evil`, and `/owner/settings`; it does **not** check a foreign origin whose path is `/owner/credit` (`tests/unit/money/stripe-customer-portal.test.ts:102-114`). **Reject the present open-redirect claim**: no user-controlled return URL reaches Stripe. If this API later accepts a caller-supplied URL, delete that argument and keep the canonical return URL; do not add a second allowlist first.
- **JOURNEY-CHATQUOTE-01 scope:** Not all x402-priced Tools: the fixed-AUD branch returns `not_required` (`convex/capabilityCallLiveX402.ts:44-48`); SEC-04 covers **managed x402** only. Current gate correctly prevents pre-approval Provider input disclosure.
- **OAuth exploit certainty:** The host omission is confirmed, but takeover requires a user to approve a deceptive client's requested scopes under strict reverification; it is neither unauthenticated grant issuance nor a proved live phishing event (`src/lib/server/agent-access-oauth/consent-security.ts:230-245,372-379`).
- **Accessibility “15 surfaces pass”:** White-hat first wave had no Clerk/Convex session, and expressly says Credit, Receipts, Team, Add Tool, Admin and real Calls were source-only; its reported 390×844 axe result is not accepted as signed-in or baseline `main` proof.

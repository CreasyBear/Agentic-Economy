# Developer experience and docs accuracy — 29 September 2026

**Scope.** `README.md`, `AGENTS.md`, and `packages/cli/README.md` against root `package.json` scripts, `packages/cli/package.json`, and `tools/ae/commands/manifest.ts`. `.env.example` against `process.env` reads under `src/`, `convex/`, and `tools/` (there is no `src/convex/tools` tree). Stale path check on those three docs plus `docs/README.md`. Tests and `convex/_generated` excluded from the env scan.

**Method.** `npm run <script>` tokens in the three docs were compared with `package.json` `scripts`. `ae <verb>` tokens in `packages/cli/README.md` were compared with root keys of `COMMANDS` in `tools/ae/commands/manifest.ts`. Env names are `process.env.NAME`, `process.env["NAME"]`, and a string literal passed to a helper in a file that indexes `process.env`. A second pass collected `env.NAME` in files whose parameter defaults to `process.env`. Names were compared with `^NAME=` lines in `.env.example` (172 unique names, 210 assignments).

**Verdict.** Every npm script those three docs name exists. Every `ae` verb in the packaged CLI README exists. `.env.example` does not list every app env var the tree reads, and it contradicts itself on the Clerk issuer the Convex process actually requires. One AGENTS path names a deleted file. The README "Run locally" block is six steps and is not sufficient to get a fresh clone to a page.

**Health score: 5/10.** Command names are real. First-run instructions and the env example are not.

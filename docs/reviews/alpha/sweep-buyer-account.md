## Not reachable and why

- Successful **fund → Quote → Call → receipt → Activity → Credit ledger → Help**: test-mode checkout returned but funding remained pending/A$0.00; browser chat could not create an exact-input Quote. No fabricated Call or receipt was used to fill the gap. An actual `/fund/$fundingSessionId` success page and `/fund/cancelled` path were not visited because completing or canceling a different session would alter the live payment experiment.
- Existing historical Call receipt: this local owner had zero Calls. Only a synthetic valid-format reference tested the refusal and Help mailto; it is not purchase proof.
- Saved unmet need create/withdraw: unique no-match query produced scoped partial coverage, not an exhaustive no-match, so the Save action correctly did not render. No separate buyer demand-list page appeared in the owner route inventory.
- Team invitations: this owner's workspace lacks a Clerk organization binding. Profile email/security mutations, key revocation, and provider/integration changes were intentionally not submitted.
- Mobile screenshots are ephemeral local files; the observed dimensions and no-overflow values are recorded above.

# G2 design — Truthful choice

## Decisions applied
- **X1:** Keep Coinbase Bazaar rows in the same bounded, navigable discovery results as admitted Tools; an external listing remains useful research, never an AE Call. Show exact-join/current eligibility **on each row/card before the click**, with distinct inspect versus Quote actions. G1 owns retrieval, classification, freshness, pagination, result shape and no-match semantics; G2 owns choice hierarchy. A publication join alone does not prove current routeability (`convex/lib/market/directoryIndex/browse.ts:14-34`; `src/modules/market/x402-directory-index.server.ts:133-139`). **Safer/intuitive**, avoiding a selectable-looking non-callable Tool.
- **X4:** One buyer presentment: AUD now (or configured default currency when actually supported), exact upstream USDC retained separately; positive nonzero sub-cent **A$0.01**, never `<A$0.01`, no independent formatter. Quote remains the actual buyer-specific decision, not the external directory estimate. Source is the existing Coinbase `USDC`→`AUD` reference (`src/modules/money/internal/reference-rate-fetch.ts:5-31`); binding managed valuation already uses its fresh rate (`src/modules/money/internal/executable-rate.ts:182-223`; `convex/lib/capabilityExecution/quotes/quoteAction.ts:87-89`). **Intuitive/safer**, replacing the misleading published-USDC/buyer-price mix.
- **X5:** Short factual recipient notice beside each query input and selected Tool input/Quote entry, derived from **verified route**, not key-name assumptions. Market hero actually enters `/t/new`, whereas Market index and canonical search can send queries plus bounded candidates to Jev; anonymous chat sends to an OpenRouter-configured gateway (`src/components/ae/market/AeX402Directory.tsx:300-318`; `src/modules/market/x402-directory-reranker.ts:23-65`; `src/modules/decision-engine/jev-client.ts:44-60`; `convex/lib/chat/anonymous/http.ts:16-27`). **Safer**, because disclosure precedes transfer; verify deployed overrides before naming the public recipient.
- **X7:** `kind: need` is *select only* → typed missing-input continuation; caller submits explicit `kind: exact` input and new purchase key → fresh exact-input AUD Quote, authority/budget and Call. No free- or paid-need argument invention, and no need-phase payment/nonce reservation (`src/modules/capability-execution/procure-engine.ts:175-233,235-303,410-453`). **Safer/ergonomic**, preserving selection without silently authorising Tool input.
- Familiar defaults: Show access and provider at result, price before action, exact input/schema before Quote, activity provenance beside its metric, compact mobile decision cards; these follow `G2-reference.md:14,25,46,56,67,78,88,99`. No second FX service, paid-search hint or consent wizard.

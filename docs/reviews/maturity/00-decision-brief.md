## 1. Cross-cutting decisions (8)

1. **X1 · What belongs in a buyer/Agent Tool shortlist?** **PC-04/05/10/20; G1/G2.** Decide whether external Bazaar listings belong inside canonical Tool search. **Options:** (a) admitted AE-callable Tools only, external listings in a separate labelled directory; (b) mixed shortlist with type/readiness filters and distinct actions; (c) remove external directory. **Familiar default:** bounded summary list → explicit detail, with listing/access distinguished ([Smithery list/detail](https://smithery.ai/docs/api-reference/servers/get-a-server), [Stripe expand](https://docs.stripe.com/api/expanding_objects), [RapidAPI access](https://docs.rapidapi.com/docs/connecting-to-an-api); `G1-reference.md:31-41`, `G2-reference.md:5-14`). **Recommend (a):** compact canonical results keep identity, fit, verified AE-callability, currency and next action; an exact-ID describe carries full schema; external directory remains honestly separate. The “callable alternative” must use eligible supply and exclude the current Tool, or return no eligible alternative. **Gate:** safer, performant, intuitive. **Challenges:** `groups` are always appended even after no-match (`src/modules/registry/tools.actions.ts:143-151`), MCP carries full structured payload (`src/lib/server/mcp-api.ts:256-270`), external GET returns raw metadata (`src/routes/api.v1.registry.ts:121-155`), Market rows omit callability and title-search can return the same uncallable row (`src/components/ae/market/DirectoryToolList.tsx:38-80`, `src/components/ae/market/public-tool-detail/DirectoryToolPage.tsx:21-28`; `G1-census.md:18-24`, `G2-census.md:6-12,37-42`). This is a surface contract choice, **not** evidence that deleting external supply improves admitted inventory.
2. **X2 · When is “no suitable Tool” justified?** **PC-02/41; G1/G6.** **Options:** (a) only after complete eligible assessment; (b) scoped no-match for assessed page with continuation; (c) no-match on any failed ranker. Do not claim a universal suitability score or full-market absence from a page.

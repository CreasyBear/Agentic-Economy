# Call any x402 service, 2026-10-09

This is a gate rationalisation: six haiku sweeps, one sonnet trace, an opus money-safety lens and an opus friction lens, then an opus architect. It was read-only. 173 gates were found.

## Verdict
"External listing" protects no money. It only means the row has not been published yet. The step that publishes it (`convex/x402Directory.ts:resolve`) runs only from chat and for one pre-admitted page, and a payer floor, a Bazaar check and an 80-item crawl decide which other rows get published. Run resolve inside Quote everywhere, accept `registry:<hex>` and HTTPS refs, and turn Bazaar, payers, eligibility and readiness clocks into ranking signals. Keep every money check, and give each refusal a category that feeds the reliability score AE already computes (`tool-selection-score.ts`).

## Call any x402 service
1. **Ref**: `operation:v1:<hex>`, `registry:<hex>`, or an `https://` URL with an agent key.
2. **Resolve** inside `quoteActionHandler`: if a current publication exists, reuse its toolRef (`choices.ts:13`). Otherwise `admitFacilitatorDiscoveryItems` and `facilitatorDiscovery.reconcile` publish it as `observed_external`, with no review. Raw URLs go through `inspectX402SellerEndpoint` first.
3. **Live 402** (`inspectLiveX402Requirement`): checks public HTTPS, no redirects, x402 v2, resource binding, a Base USDC exact EIP-3009 lane and an unchanged payTo. The live amount is the price.
4. **Quote**: AUD price within agent limits, credit, legal exposure and treasury. Valid for 5 minutes.
5. **Pay and verify**: the call worker holds funds and re-reads the 402. After screening and custody caps it signs only the quoted amount, then validates the output. `x402-evm-receipt-reader` confirms the transfer before settlement and receipt.

**Caps**: agent per-call, daily and monthly limits. Custody limits are USDC 0.5 per Call, 0.5 per new payee, 2 per payee daily and 10 daily (`docs/operations/deployments.md:114`).
**Failure**: a refusal before signing releases the hold, so nothing is charged. After submission, `reconcileDueFacilitatorInvocations` reads the chain and never retries blind. Paid but invalid output is charged, capped, and counted against that provider only.

## What becomes a signal
- **Success rate**: `(completed+1)/(completed+failed+2)`, counting provider-side failures only (`marketListingEvidence:selectionEvidence`).
- **Latency**: p50 `durationMs` of completed Calls.
- **Last verified**: the latest quote probe or Call.
- **Payers**: Bazaar 30-day payers; fewer than 2 shows "new".
- **Schema**: declared or undeclared; the quality bar shows as a badge.

Every row shows these in the CLI, MCP, web and chat. Ranking puts relevance first, then `scoreToolEvidence` (reliability 0.4, payers 0.3, price 0.2, used before 0.1, minus buyer reports). Signals never filter unless the caller asks.

## Antifragility
- **Health**: every probe and Call writes evidence. A new kind, `ae_invocation_refused` (`marketEvidenceFacts`), records the category.
- **Demotion**: each provider-side failure lowers reliability at once, so search, `tool.procure` and chat pick the next best. AE-side faults (`payment_unavailable`) never count against a provider.
- **Retries**: only before signing: one re-quote on `price_changed` or expiry, and one retry on stale money reads.
- **Circuit breaking**: the quote probe is the half-open check. A dead endpoint fails without charge and drops in ranking; one good probe restores it.
- **Learning**: counts of stored reasons pick the next payment rail (Solana if `chain_unsupported` leads) and flag spikes in `payee_changed`.

## Risks you must not remove
1. Live 402 binding: payTo, network and asset stay fixed from Quote to Call, and AE never signs above the quote.
2. Custody and new-payee caps, treasury freshness, and screening that fails closed (the alpha policy records "not screened", never "clear").
3. The SSRF guard on probes, and raw-URL resolve only with an agent key (`resolve` is a public action today).
4. Exactly-once money: hold, release before signing, idempotency, chain reconciliation.
5. Environment isolation and the payments audience. Production reads `admins`, and opening it is Joel's launch decision.

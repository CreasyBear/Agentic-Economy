# Research archive

The files in this directory preserve dated benchmark studies, architecture
comparisons, implementation evidence and proposed mechanisms. They are inputs to
product decisions, not active product authority.

Use the root documents for current direction:

- [`PRODUCT.md`](../PRODUCT.md) defines the product and commercial model.
- [`AGENTIC_ECONOMY_AUSTRALIA_WHITEPAPER.md`](../AGENTIC_ECONOMY_AUSTRALIA_WHITEPAPER.md)
  explains the institutional thesis.
- [`CONTEXT.md`](../CONTEXT.md) defines canonical language.
- [`START_LINE.md`](../START_LINE.md) defines the current proof.
- Current source and tests define implemented behaviour.

Research may describe an earlier market loop, call a Provider a "supplier" or
"seller", propose an inactive roadmap, or compare code that has since changed.
Read each claim at its stated evidence date. Do not promote a recommendation
into product scope without reconciling it against the root authorities and
current source.
